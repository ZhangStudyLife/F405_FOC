## 直接证据

- CSV 从 IDLE 进入预充/RUN，19 次成功命令后都有与八音、4.8 秒吻合的电流段。
  CSV 不包含命令文本，因此只确认时序吻合。没有故障或发送丢帧，母线 24.267～24.660 V。
- 全程是转矩模式、运动 Iq 目标 0 A，发声主要在 Id。尽管录音名含 IQ，不能据文件名认定 Q 轴注入。
- 原始编码器角度范围约 266.913～268.839°，报告瞬时速度 −53.13～44.63 rpm。
  没有持续旋转，但发声时存在小幅角度波动；它可能含真实摆动及编码器测量干扰，不能宣称转子绝对静止。
- Id 的记录极值为 −17.243/+17.671 A；逐音拟合值见下表。音乐电流明显存在，
  但 20 A 目标没有完全跟随，且越高的音衰减越明显。
- 非播放的 RUN 区间，Id/Iq 回传 RMS 约 0.214/0.181 A。零偏原始电压噪声
  B/C 为 3.316/3.507 mV，按代码换算分别约 0.166/0.175 A；回传中的波动包含采样噪声，
  不能直接认定这些数值全是物理电流振荡。
- 录音中能找到四组 C4～C5，以及明显二倍频和其他谐波。C5 的基频较弱，
  1046 Hz 二倍频、约 3663 Hz 七倍频反而更突出，说明声音不是理想纯正弦。
- 播放间隙/录音尾段可见约 2.3 kHz、4.6 kHz 等弱窄带分量及宽带背景。
  手机可能带 AGC、降噪和频响处理，未校准声压；不能将 dBFS 换算成电机 SPL，
  也不能仅凭录音把某条频谱线确定为 PI 自激或 PWM 载波。

## 如何理解声音轻和“不发烫”

现在已经是十几安培的 D 轴交流电流；不是没有播放。电流目标与反馈仍有差距，
而径向磁力到壳体振动、再到空气声压的效率尚未测量，这两部分都应检查。
如果只是把本次实际分量补足到 20 A，电流幅值增益约 1.7～4.2 dB；
声音含非线性谐波，这不是声压提升预测，也不能承诺会变得非常响。

20 A 是 dq 矢量目标峰值，不是每相 20 A RMS。按名义相电阻 0.12 Ω 和理想正弦，
铜耗为 `1.5 R (Id_rms²+Iq_rms²)`；本次拟合音符对应稳态铜耗约 14～24 W，
间隔和渐变会进一步降低平均功耗。相电阻和温度均未本轮实测，短时摸外壳不热
不能推导绕组温度、允许持续电流或继续增加限流/过流阈值的依据。

## 实施的最小改动

1. 正常 `music play` 保持 D 轴注入，运动 Iq 和速度/位置模式不变，播放结束仍保持 PWM/RUN。
   未实施“零速关闭 PWM”方案。
2. 在原 PI 和旋转解耦外加入音乐电压前馈：
   `u_audio = R I_audio + L d(I_audio)/dt`。
   使用现有名义 R=0.12 Ω、L=50 µH，解析计算正弦与 20 ms 包络的导数；
   前馈相位/包络提前 50 µs，约对齐下一 PWM 中心。未微分 ADC 噪声。
3. PI 的比例误差用 2 kHz 一阶低通，更新系数 `1−exp(−2π×2000/20000)=0.4665119`。
   积分仍使用原始误差，电流换算和 25 A 相电流保护仍使用原始采样。
   这是抑制采样噪声驱动高频调压的候选，尚未证明它就是本机待机尖声的原因。
4. 经用户确认增加独立 `music play q`，同一八音阶、2 A 峰值，启动限于静止零转矩模式。
   它会产生振动转矩；仅作静止试听对照，正常旋转发声仍用 D 轴命令。
   20 A dq 目标预算和 25 A 相电流保护保持不变。

电压模型与 PI 关系可参考 [Infineon 应用说明，式 17～21](https://www.infineon.com/assets/row/public/documents/24/42/infineon-80v-3.5kw-bldc-motor-driver-inverter-applicationnotes-en.pdf)。
前馈能否精确跟随仍依赖本机 R/L、实际保存的 PI、死区及采样/PWM 延迟，不能把名义参数当重新标定。

## 验证结果及下一次对照

直接编译实际 music.c/foc.c/control.c 的临时本机检查已通过：
八音频率误差小于 0.001 Hz；D/Q 峰值分别为 20/2 A；两轴不会同时产生音乐目标；
渐变、静音、停止、dq 预算及前馈公式符合设计。
名义 R/L、额外一个 PWM 周期延迟的线性模型，Id 稳态分量为目标的约 102%～106%；
模型验证速度/位置模式的运动 Iq 未被 D 轴音频改写、音乐结束保持 RUN、原始过流仍停机。

同一模型中，向 ADC 电流反馈加 0.2 A 峰值的窄带噪声，P 通道低通使由噪声驱动的
物理电流分量在 2.308/4.660 kHz 分别降低约 2.8/7.8 dB，1.538 kHz 则增大约 0.4 dB。
这是模型的电流结果，不是实测声压；低通不会消除所有频率的噪声，也会改变环路相位。

MUSIC_ENABLE=0/1 的 Debug/Release 均构建通过，最终开关为 1。
最终 Debug Flash 51068 B、Release 41412 B，RAM 均为 3648 B。
本轮没有连接硬件或烧录，因此响度、尖声、实际电流、温升、实时性和旋转稳定性仍未验收。
临时脚本、结果及频谱图在本地 `build/music_analysis_20a/`，不加入永久测试框架。

烧录后固定手机位置、增益和电机安装方式，在同一录音中依次留出：
无音乐 PWM 开启背景、`music play`、背景、`iq 0` 稳定后 `music play q`、背景。
同时记录当前 20 通道 CSV；Q 轴试听时通道 2 会显示总 Iq 目标。
正常 D 轴试听还需在已验证的低转速闭环重复，比较转速误差、电流和故障。
若补偿后的实际电流接近目标而音量仍不足，应测径向声学频响/安装结构；
若尖声没有下降，应采集短时 20 kHz 原始电流与 PWM 电压定位，不能继续凭 500 Hz FFT 调 PI。
