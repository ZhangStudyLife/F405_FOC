## 为什么 20 A 与 2 A 听感没有相差十倍

这是 D/Q 两个方向的对照，不能用目标电流倍数推导声压倍数。
录音前五次谐波窄带总能量的逐音平均，中位数 D 轴约比 Q 轴高 3.5 dB；
差异随音符变化：C4/D4 的 Q 轴录音分量反而更强，F4/G4 的 D 轴约高 9.6/11.5 dB。
这与“整体差别不大，20 A 稍响”的描述相容，也显示声学响应不均匀。
该指标只比较手机记录中的选定频带，包含 AGC、环境和机械响应影响，不是校准声压或听感响度测量。

`7e11528705d3987bfbf875bb0c365ac923f3fb6fe3cb5e179062f3d519f54d69`。
RAM 当前电流增益为 Kp=0.18849556、Ki=452.38934，与默认值一致；本次没有修改或保存参数。

新旧比较同时包含前馈、比例低通及不同测试记录，尚不能独立测出前馈贡献。
名义线性模型给出的约 102%～106% 跟随没有在这次数据中得到支持，不能继续把模型当实测。
当前 CSV 缺少 Id 目标、输出电压和限幅比例，无法据它确定应改变 R/L、PI、延迟还是逆变器补偿。

因此本次没有按 `20/实际幅值` 提高目标，也没有加入逐音经验增益或修改 PI。
下一次调整应由同条件前馈开/关及同步目标/反馈/电压数据决定，仍在 20 A 目标预算内进行。

1. 录音八音均在目标 ±5 音分内，顺序、持续时间和重复播放一致。

3. 电流二至五次谐波合成比例 ≤5%，三次同工况增益差 ≤5%；检查限幅和交叉轴扰动。
4. PWM/采样/编码器/过流保护正常、无通信丢帧，音乐关闭后 Id 目标为零且保持正常 PWM。
