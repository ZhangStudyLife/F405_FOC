# 低波动速度控制实验版本（2026-10-03）

本版本已实现并做初轮实测，**尚未满足验收要求**。+1000 rpm 的完整 Iq 目标标准差约
0.180 A，仍高于 0.02 A。独立启动 −1000 rpm 时，编码器再次报告欠压，立即保护停机。
需要处理告警并继续辨识、整定和对照；不要把本版本当作已经验收的控制参数。

## 实现与依据

- 电流环仍为 20 kHz，外环 PI/位置仍为 1 kHz，JustFloat 仍为 20 通道、500 Hz、84 字节。
- 三状态位置/速度/负载估计器按 20 kHz 更新，输入为实际 Iq 和已经通过保护检查的机械角度。
  原有 0.52° 二次谐波角度修正保留。原有 `foc.rpm` 用于电角速度计算和独立超速保护；
  通道 4 是新估计器用于速度环的速度，通道 8 仍为原始绝对角度。
- 状态结构参考 [Xia 等的绝对编码器 PMSM 研究](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/iet-epa.2014.0516)。
  本实现使用固定增益的三状态观测器，**没有实现该论文的自适应 Kalman 协方差更新**。
  临时小扰动辨识得到机械增益约 4686 rpm/s/A；观测器连续极点为 −200 rad/s 三重极点，
  `Lθ=3w`、`Lω=w²/2`、`Lload=−w³/(6A)`，按原生采样率预测及修正。
  这些观测器增益仍需联合整定，不能用模型预测稳定裕量代替实测。
- PLL 回放参考 [moteus](https://github.com/mjbots/moteus/blob/8f747f4ac448d117c1390b77ca2d80c27e751a56/fw/motor_position.h)。
  本轮模型/回放中降低 PLL 带宽会损失速度反馈相位，未找到同时保留高增益响应与低波动的组合。
  固件仅保留上述三状态估计器作为外环测速。
- 速度控制为增量二自由度 PI：`Δu=Kp·Δ(βr−v)+Ki·dt·(r−v)`，当前 β=0.8。
  输出状态用加入前馈后的最终 Iq 限幅进行反算，跟踪时间为 `Kp/Ki`；不裁剪参考权重产生的
  大直流积分偏置。参考 [Wang 等](https://article.nadiapub.com/IJCA/vol9_no12/6.pdf)。
  现有七个 `set`/`save` 参数和 Flash 记录格式不变。
- 低速前馈为 512 点只读表（2048 字节），按原始绝对机械角度线性插值。
  方法参考 [Piccoli/Yim](https://www.roboticsproceedings.org/rss10/p42.pdf) 和
  [ODrive](https://github.com/odriverobotics/ODrive/blob/3a2e4dd1bfbda9e4c534d5c7d8428a99c361e783/Firmware/MotorControl/controller.cpp)。
  正反向各四圈，前三圈用于角度分箱和跨圈/方向重复性筛选，第四圈独立验证。
  去除各圈直流量；方向平均用于保留重复的角度相关项。本机校准方向为 +1。
  标定数据证明重复的转矩请求，不能单独证明这些项都是真实齿槽转矩。
- `zero`、`clear` 和重启不改变表的绝对角度索引。临时 SRAM 缓冲、扰动注入和测试电流上限已移除。
  现有硬限值仍为 Iq 8 A、瞬时相电流 10 A，保护未屏蔽。

50～200 rpm 的前馈线性退出区间目前为**实验值**，没有完成计划要求的五个转速开关对照。
β=0.8 的阶跃/反转响应也未完成本机验收。未取得调制饱和导致外环积累的证据，未另加电压限幅逻辑。

## 标定来源与主机入口

原始 CSV、原生采样、临时检查及报告目录：
`build/bench_debug/20261003_030219/`。
表来源为 `baseline_low.csv`；第四圈去直流的电流周期量残差 RMS：
正向 0.1483→0.0082 A，反向 0.1449→0.0077 A。这是离线表验证，不能作为闭环运动通过证据。
使用固件的实际插值方式，在第四圈全部未平均采样上验证，残差 RMS 为 0.0186/0.0176 A。

在本工作区使用现有 `../auto_rpm/auto_rpm.py` 的 20 通道解析器：

```powershell
python tools/speed_control.py cog
python tools/speed_control.py fit build/bench_debug/<目录>/cog.csv
python tools/speed_control.py accept
python tools/speed_control.py report build/bench_debug/<目录>/accept.csv
```

`cog` 用于重新采集正反向四圈；已开启前馈的版本不能直接用于重新标定，需使用标定前基线版本。
`fit` 更新编译表，并保存来源及独立验证指标；更新后需重新构建。
`accept` 采集六个高速点各三次、低速和原 300 秒波形，故障立即停止并确认功率关断。
该入口不自动校准、不自动清除故障，也不自动保存未经验收的增益。
输出含命名和单位的 CSV、串口原始字节及停机记录。

Iq 指标始终统计完整目标，不作离线滤波或减去前馈。原始角度测速对所有版本统一使用
500 Hz、25 点三阶 Savitzky–Golay 导数，仅用于相同方法的运动对照；高速混叠仍须原生采样复核。
响应时间须用临时 MCU 时间戳采集，USB 接收时间不能当作准确控制时间。

## 本轮验收状态

完成基线 ±1/±5/±50/±1000/±3000/±5000 rpm、双向四圈、原生采样、小扰动辨识。
改进版只完成 +1/+5/+50/+1000 rpm 短测；−1000 rpm 启动触发 CRC 正确的欠压告警。
首次异常帧 `3E 02 A4 92`，状态值 4、CRC 0x92 正确；ADC/PWM/编码器时序计数均为零。
参考 [MT6835 Rev1.3](https://www.magntek.com.cn/upload/pdf/202407/MT6835_Rev.1.3.pdf) 的状态位定义。
仅有串口和 ST-Link 时，无法确认传感器供电瞬态的具体根因。

完整高速三次重复、低速闭环完整圈对照、响应 ≤10% 余量、前馈退出区间、正式 300 秒波形
均未验收。声压、机械振动和温升没有测量设备，未测。现有速度增益 0.1/2 保留，未保存新的验收参数。
