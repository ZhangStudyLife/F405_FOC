# ADC 上板采集验收

## 当前 M1 配置（2026-09-20）

- ADC1_IN13 / PC3 / M1_SO1：B 相低侧分流放大器输出。
- ADC2_IN12 / PC2 / M1_SO2：C 相低侧分流放大器输出。
- 双 ADC 注入同步，各两个 rank，12 位右对齐；21 MHz ADC 时钟。第一 rank 为 B/C 同步采样（28 cycles），第二 rank 两 ADC 均采 PA6 母线（15 cycles），只使用 ADC1 的母线结果。序列约 3.190 us，不含触发同步延迟。
- TIM8 中心对齐，PSC=0、ARR=4200，CH4 Toggle、CCR4=4100、上升沿触发。
  硬件采样、adc_m1 与 adc_bus_voltage 更新均为 20 kHz（50 us）；ADC2 不独立触发，仅 ADC1 开完成中断。
- adc_m1 仅含 b_voltage / c_voltage，单位 V；raw × (3.3 / 4095)，保留放大器偏置，
  不换算电流、不乘母线分压倍率。3.3 V 为标称参考，尚未做精度校准。
- adc_bus_voltage 为实际母线电压（V），ADC1_JDR2 × (3.3 / 4095) × (41.2 / 2.2)，对应 PA6 的 39 kΩ / 2.2 kΩ 分压。母线在 B/C 之后采样，不与 B/C 同时。第二 rank 使结果发布较原单 rank 延后约 1.286 us，后续 FOC 需计入控制延迟。
- 每 20 对成功采样发送一次三路 JustFloat 电压，串口观察为 1 kHz，采样不降频。
  每帧为 float 毫秒时间戳、B 相电压、C 相电压、母线电压、+Inf，共 20 字节。
- 两路完成状态检查通过后才更新结构体；异常时计错并停止采集，不发布半组结果。
- 六路栅极引脚保持 GPIO 低，仅使能 CH4。固定 CCR4 尚未验证带功率采样窗口。
  后续 FOC 必须保证 B/C 低侧在整个采样窗口内稳定导通，并留出死区、开关和运放建立时间；
  窗口不足时调整调制或触发点。前台读取一致的两字段快照时需短暂屏蔽 ADC IRQ。

### 本次优化与实测（2026-09-20）

仅将母线 rank 从 144 cycles 改成 15 cycles，B/C 仍为 28 cycles；未提高 ADC 时钟或缩短电流通道采样窗口。
母线分压戴维南电阻约 2.08 kΩ，ADC 输入处有 100 nF 电容。保留两个同步 rank、原中断和接口，不引入第三 ADC、DMA 或额外中断。
完整转换从 196/21 MHz = 9.333 us 缩短为 67/21 MHz = 3.190 us，减少 65.8%。这属于 ADC 硬件转换延迟，不是 CPU 忙等时间。

Release 对母线 144 / 28 / 15 cycles 分别烧录、校验并进行约 10 秒串口采集，最后复测 144 cycles。
以下为 1 kHz 抽取样本统计，不代表全部 20 kHz 原始样本或带宽内噪声：

| 母线采样 cycles | 序列理论耗时 us | 母线均值 V | 母线标准差 mV | 临时 ISR TIM8 相位 ticks |
|---|---:|---:|---:|---:|
| 144（初测） | 9.333 | 4.49065 | 8.585 | 5713～5729 |
| 28 | 3.810 | 4.49386 | 6.696 | 4785～4801 |
| 15 | 3.190 | 4.49535 | 5.970 | 4683～4699 |
| 144（复测） | 9.333 | 4.49128 | 8.368 | 5713～5729 |

相位测量在 ISR 内读取 TIM8 CNT/DIR，向下时换算为 8400−CNT；临时测量代码已移除。
本工程复位启动时 CH4 上升沿位于向上计数 CNT=4100。15 cycles 的触发至相位读取约 3.47～3.57 us，较 144 cycles 提前约 6.13 us；该数值包含触发同步、中断进入和测量指令，不能当作纯 ADC 转换时间。
中心对齐模式 1 的 CC 中断标志方向限制不能直接等同于 Toggle OCREF 的翻转方向。

最终版移除临时字段后重新烧录 Release，STM32CubeProgrammer 回读校验成功；探针 8600A1002031363534313541，F405 系列 ID 0x413、1 MB。

- Debug / Release 均构建通过，无编译警告；git diff --check 通过。
- COM14、3.5 Mbps，约 30 秒读取窗口获得 30,490 个连续有效 JustFloat 帧，无内部坏帧，时间戳间隔全为 1 ms。串口在 SWD 起始读取前已打开，因此帧数包含预先缓冲的数据，不能直接除以读取窗口时间计算采样率。
- 最终固件累计 1,692,846 对样本时：不完整对=0、发送拒绝=0，DWT 周期间隔 8385～8410 cycles，约 50 us。独立主机窗口约 5.406 s 增加 108,211 对，估算约 20.017 kHz；该主机估算含 SWD 查询时间误差，不是晶振校准。
- 现有 ISR 测量区间最大 288 cycles = 1.714 us，包含每 20 次一次的发送提交，不含完整异常进出栈和函数序言/尾声。原 144-cycle 未插桩基准为 291 cycles；本次主要减少结果延迟，不宣称显著降低 CPU 占用。
- 最终 B/C/母线均值：1.66176 / 1.68235 / 4.49380 V；标准差：0.454 / 0.455 / 7.073 mV。不同批次均值存在电源漂移，静态数据没有观察到缩短采样带来的明显噪声增加，但不能证明全量程精度。
- SWD 寄存器确认 ADC 通道、采样时间、双注入模式及 TIM8 PSC=0、ARR=4200、CCR4=4100；CCER 仅 CH4。六路栅极 GPIO 的 MODER/OTYPER/ODR/IDR 均符合推挽低电平，未测实际栅极波形。
- 本地原始串口数据、JSON 统计、烧录日志及最终寄存器快照保存在 build/adc_optimization/（构建产物，不纳入版本管理）。

仍待台架验证：已知输入电压、实测 VDDA 与母线万用表校准；母线动态变化/全量程条件；MOS 开关下模拟建立时间及带载电流精度。当前约 4.49 V 的静态母线测试不能代替这些验证。

## 实现与范围

- `bsp_adc` 固定 ADC1/ADC2、各两档，去掉任意句柄、可选从机和 1～4 档抽象。
- 先检查双 ADC 模式、通道顺序、分辨率、对齐、扫描、ADC 时钟、采样时间及触发源。
- 只开 ADC1 JEOC 中断；读取前检查两个 ADC 都完成，读取四个 JDR 后只清注入标志。
- `adc_test` 负责计数和周期统计，不依赖编码器、PI、SVPWM 或电流换算。
- 主循环每 1 ms 用 `HAL_UART_Transmit_DMA(&huart2, ...)` 发送一帧 16 字节 ADC 原始调试数据；DMA 忙时跳过，不阻塞采样 ISR，USART2 IRQ 负责 DMA 发送完成收尾。
- 配置错误时不启动定时器；主从完成状态不一致时计错并停止采集，避免使用旧值。
- 旧 FOC 装配代码保留但不参与构建；撤下旧文档中不可复核的实测表和带功率校准步骤。
- 删除链接脚本里保留未调用调试函数的 `.foc_debug` KEEP。

## 触发与功率引脚

TIM8 中心对齐，168 MHz，PSC=0，ARR=4200，CH4 Toggle，CCR4=4100，
ADC1 选择 TIM8_CC4 上升沿。ADC2 从主 ADC 同步启动。
ADC 时钟 21 MHz，rank1 为 28 周期采样，rank2 为 15 周期采样。

F405 注入组没有 TIM8_TRGO 选项。本轮实测 CH4 触发受 MOE 门控：
关闭 MOE 后两次计数均为 616515，恢复后达到 620539。
因此测试用 MOE=1、CCER=0x1000，只使能 CH4。
PA7、PB0、PB1、PC6、PC7、PC8 从定时器复用切换为推挽 GPIO 低电平。
脚本检查 MODER、OTYPER、ODR、IDR；这不是对栅极电压的测量。

当前 CCR4 仅用于验证触发与采集。没有带 PWM 测过低侧有效采样窗口，
不能将这个测试初始化直接用于电机运行。

UART2 调试帧格式为小端序：`A5 5A`、uint16 序号、4 个 uint16 原始值（PC3、PC2、PA4、PA6）、uint32 ADC 帧计数。
串口参数为 460800、8N1、无流控；PA2 接 USB-UART RX，必须共地。

## 实测结果

Debug / Release 均构建无警告，分别烧录并通过 OpenOCD verify。
另用约 2 秒主机计数差验证持续运行。

- 连续帧间隔：8399～8402 CPU 周期；按标称 168 MHz 换算为约 20,000 Hz。
- 主从完成异常：0。启动后的周期极值检查也通过，没有出现整拍丢失。
- 追加连续运行检查：10.001653 秒新增 200035 帧，主机估计 20000.19 Hz；
  累计 2186345 帧时异常仍为 0，周期极值为 8385～8400。
- 六路功率引脚均为 GPIO 推挽低电平，CH1～CH3 和互补输出均未使能。
- Release ISR 测量区间最大 240 周期，约 1.43 µs；
  不包括异常进出栈、完整函数序言/尾声，不能当作未来整套 FOC 电流环耗时。
- 启动后的首个周期存在约 15～17 周期的差异；上述固定间隔来自稳定运行窗口。

未验证已知电压输入的 ADC 精度、电流增益/极性、母线分压或温度公式；
晶振绝对误差未用外部仪器测量。主从 JEOC 与配置检查验证了数字采集完整性，
没有通过外部激励测量两路模拟孔径之间的偏差。

## UART2 DMA 验证

Debug 固件通过 SWD 先停发周期测试帧，确认 UART 空闲后调用一次
`HAL_UART_Transmit_DMA()`，返回 `HAL_OK`；恢复运行 100 ms 后观察到
`huart2.gState=READY`、DMA `NDTR=0`、`CR=0`。这验证了 DMA1 Stream6
搬运和 USART2 发送完成中断收尾。当前电脑未检测到可用 USB-UART 适配器，
因此 PA2 到上位机的实际字节抓取仍需接入 3.3 V 电平串口适配器后进行。

## 故障路径验证（Debug，上板）

1. 在 `bsp_adc_start` 入口硬件断点处，将 ADC2_JSQR 清零再继续：
   `started=0`、`samples=0`，TIM8 CEN=0，配置不匹配被拒绝。
2. 复位，在第一次 `adc_test_isr` 入口断点处清 ADC2_SR 再继续：
   `incomplete_pairs=1`、`samples=0`，TIM8 CEN=0，未发布不完整帧。
3. 每项后复位恢复原配置。最终重新烧录正常 Release 固件，保持连续采集。
