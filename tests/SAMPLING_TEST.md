# 采样链路验证（ADC / MT6835 / 20 kHz 时序）

本文覆盖 20 kHz 采样链路：触发与转换调度、ADC 采样时间优化、周期与 CPU 口径、MT6835 编码器和板上故障注入。
FOC 控制见 [FOC_TEST.md](FOC_TEST.md)，两种回传见 [USB_TEST.md](USB_TEST.md) 与 [UART_TEST.md](UART_TEST.md)。
当前链路参数以 [App/README.md](../App/README.md) 的"采样链路"为准；本文只记录可复核的历史验收数据。

## 当前链路全貌

- TIM8 中心对齐，168 MHz、PSC=0、ARR=4200、RCR=1，三相预装载在谷底统一生效；CH4 Toggle、CCR4=4100，
  OC4REF 作为 TRGO 每 50 µs 触发一次双 ADC 转换。
- ADC1 rank1 = PC3/IN13（B 相低侧分流放大器），ADC2 rank1 = PC2/IN12（C 相）；rank2 两 ADC 均采 PA6/IN6（母线）。
  ADC 时钟 21 MHz，采样时间分别 28 / 15 cycles，完整序列约 3.19 µs。
- DMA2 Stream0/Channel0 循环读取公共 CDR，每次两个 32 位字，第一个字完成后半传输中断；
  半传输中断启动 SPI3（Mode 3、10.5 MHz）DMA 读磁编，与母线第二 rank 转换重叠。
- SPI RX DMA 完成中断校验 CRC 与传感器状态、更新 `mt6835_angle_deg`，确认两个 rank 完成后发布三路电压，
  再调用 `app_sample()`；回调执行 FOC 并在下一谷底前写入三相预装载，每 10 次回调提交一帧遥测。
- IRQ 优先级：ADC/SPI DMA 为 1；TIM8 更新、ADC 错误、USART2 RX 为 0；USB 为 7。TIM5 由 BSP 配置为 1 MHz
  自由运行计时，专用于 ADC DMA 入口的微秒时间戳，不能另作他用。
- `adc_sample` 使用标称 VDDA=3.3 V，保留电流放大器偏置；母线倍率 41.2/2.2。ADC overrun 或 DMA 错误会停止
  采样并置 NaN；编码器 CRC/状态/DMA 错误输出 NaN，计数在 `adc_errors`、`mt6835_errors`。
- 启动时转子静止 200 ms 后采集 2048 对样本，独立估计 B/C 零偏与方差；零偏不存 Flash。
  默认电流换算 `(V - offset) / 0.020` A，增益与极性仍需已知电流标定。

**与历史记录的区别**：2026-09-14～09-20 的验收使用**双 ADC 注入组同步**配置；2026-09-20 重构（提交
`3f59f51`）改为上表的**规则组同步 + DMA** 路径。因此下面的注入组数据属于历史口径，不能与当前寄存器配置混用。

## 历史：注入组同步采样验收（2026-09-14 / 09-18 / 09-20）

当时配置：双 ADC 注入同步、各两个 rank、12 位右对齐、21 MHz；rank1 同时采 B/C（28 cycles），rank2 两 ADC
均采母线（15 cycles，只用 ADC1 结果）；TIM8 CH4 触发受 MOE 门控（实测关闭 MOE 后两次计数停在 616515，
恢复后到 620539，因此测试期 MOE=1、CCER 仅使能 CH4）；PA7/PB0/PB1/PC6/PC7/PC8 切换为推挽 GPIO 低。
只开 ADC1 完成中断，读取前检查两个 ADC 都完成；状态不一致时计错并停止采集，不发布半组结果。
母线在 B/C 之后采样，第二 rank 使结果发布较单 rank 延后约 1.286 µs，后续 FOC 必须计入该控制延迟。

### 母线采样时间优化

只把母线 rank 从 144 cycles 改为 15 cycles（B/C 保持 28 cycles），保留两个同步 rank 与原接口：

| 母线采样 cycles | 序列理论耗时 | 母线均值 | 母线标准差 | 临时 ISR TIM8 相位 ticks |
|---:|---:|---:|---:|---:|
| 144（初测） | 9.333 µs | 4.49065 V | 8.585 mV | 5713～5729 |
| 28 | 3.810 µs | 4.49386 V | 6.696 mV | 4785～4801 |
| 15 | 3.190 µs | 4.49535 V | 5.970 mV | 4683～4699 |
| 144（复测） | 9.333 µs | 4.49128 V | 8.368 mV | 5713～5729 |

完整转换由 196/21 MHz = 9.333 µs 缩短到 67/21 MHz = 3.190 µs（−65.8%），属于 ADC 硬件转换延迟，
不是 CPU 忙等时间；统计来自 1 kHz 抽取样本，不代表全部 20 kHz 原始样本或带宽内噪声
（证据：`build/adc_optimization/*_summary.json`、`final_rate.json`、`final_registers.json`）。

### 同期采集结果

- COM14、3.5 Mbps、约 30 秒窗口获得 30,490 个连续有效 JustFloat 帧，无内部坏帧，时间戳间隔全为 1 ms。
  串口在 SWD 读取前已打开，帧数包含预先缓冲数据，不能除以窗口算采样率。
- 累计 1,692,846 对样本时：不完整对 0、发送拒绝 0、DWT 周期间隔 8385～8410 cycles（约 50 µs）；
  ISR 测量区间最大 288 cycles（1.714 µs，含每 20 次一次的发送提交，不含完整异常进出栈与函数序言/尾声）。
  主机窗口 5.406 s 增加 108,211 对，估算约 20.017 kHz——该估算含 SWD 查询误差，不是晶振校准
  （`final_rate.json` 的 `estimated_rate_hz=20016.83` 同源）。
- 最终板上均值：B 1.66176 V、C 1.68235 V、母线 4.49380 V，标准差 0.454 / 0.455 / 7.073 mV；
  静态数据未观察到缩短采样带来的明显噪声增加，不能证明全量程精度。
- SWD 寄存器确认 TIM8 PSC=0、ARR=4200、CCR4=4100、CCER 仅 CH4；六路栅极引脚 MODER/OTYPER/ODR/IDR
  均为推挽低电平。这是寄存器检查，不是栅极电压测量。
- 更早的 2026-09-18 母线单独测试：ADC1 独立模式、单注入通道 6、TIM8 PSC=19/ARR=4200（1 kHz）、
  采样 144 cycles，约 10 秒抓取 9987 个连续帧、逐帧间隔 1 ms、平均 4.471 V。
- 2026-09-14 多通道历史验证：`A5 5A` + 序号 + 4 路 uint16 + 帧计数共 16 字节、460800 baud；
  10.001653 秒新增 200,035 帧（约 20000.19 Hz），累计 2,186,345 帧异常为 0，周期极值 8385～8400；
  ISR 测量区间最大 240 cycles（1.43 µs）。原始码均值/标准差：PC3 2062.645/1.490、PC2 2088.180/1.590、
  PA4 1145.385/1.832、PA6 796.554/1.627。这些是偏置观测，不是永久零偏标定。

### 代码级故障注入（Debug，上板）

1. 在 `bsp_adc_start` 入口断点处清 `ADC2_JSQR` 后继续：`started=0`、`samples=0`、TIM8 CEN=0，配置不匹配被拒绝。
2. 复位后在第一次采样 ISR 入口断点处清 `ADC2_SR`：`incomplete_pairs=1`、`samples=0`、TIM8 CEN=0，
   未发布不完整帧。

每项后复位恢复原配置，最终重新烧录正常 Release 并保持连续采集。

**来源说明**：MOE 门控计数（616515 / 620539）、2026-09-18 母线单独抓取（9987 帧、平均 4.471 V）、
2026-09-14 多通道验证和上面的代码级故障注入计数，唯一来源是重构前的 `tests/ADC_TEST.md`
（git `3f59f51^`，该文件已随重构删除）；本机未保留这些原始日志，按原文转录，无法再用 `build/` 复核。
本节其余 ADC 优化表与采集统计都可用 `build/adc_optimization/` 复核。

## 周期与 CPU 口径

| 来源 / 口径 | 周期 | 其他 |
|---|---|---|
| 2026-09-14 注入组历史 | 8385～8400 cycles | ISR 最大 240 cycles |
| 2026-09-20 临时插桩（最终固件已移除） | ADC DMA 完成周期 8391～8409 cycles（49.946～50.054 µs） | ADC 发布 + SPI DMA 启动平均约 0.72 µs、最大 155 cycles；SPI 完成 + 解码 + 20 分频上传平均约 1.10 µs、最大 405 cycles；两段最大值之和 560 cycles（3.333 µs）；ADC IRQ 入口至编码器处理完成最大 1453 cycles（8.649 µs）。**转录**：此前固件 ADC ISR 最大 1933 cycles（11.506 µs，含 SPI DMA 忙等） |
| 2026-09-20 电压模式最终版 | 8310～8494 cycles（49.464～50.560 µs） | ADC DMA 入口到 FOC/遥测结束最大 3159 cycles（18.804 µs） |
| 2026-09-21 电流迭代 | 8280～8526 cycles | `motor_work_max=4693`，最小 CCR 提交 CNT=797（要求 ≥600，余量约 1.17 µs） |
| 2026-09-22 正式 Release（电机关闭） | 8384～8416 cycles（49.905～50.095 µs） | `motor_work_max=3528 cycles`（21.00 µs） |
| 2026-09-22 插桩 + USB 8 通道 | 8368～8436 cycles（49.81～50.21 µs） | 采样 ISR 最大约 15.24 µs，`motor_work_max` 最高 3608 cycles（21.48 µs），控制时序故障 0 |

口径说明：`motor_work_max` 是采样链路墙钟跨度（ADC DMA IRQ 入口到应用处理结束，含 SPI 等待与被抢占时间），
不是纯 CPU 占用；DWT/ISR 数字含函数序言、尾声与统计指令，不含完整异常进出栈。两者不可互相比较，
也不能直接当作 PWM 提交裕量；提交裕量用 `motor_write_min`（最小 CNT）判断。
临时插桩固件在持续窗口内累计约 158 万次 ADC 中断，ADC/编码器错误均为 0；插桩代码已从最终固件移除。
以上都是电机关闭或无负载工况，不证明带转矩运行时的截止裕量。

插桩数字的原始依据是 `build/refactor/instrumented-board.txt` 的 `g_profile[10]` 转储
（`[0..2]` 段 1 计数/累加/最大，`[3..5]` 段 2 计数/累加/最大，`[6..7]` 周期最小/最大，`[8]` 入口至处理完成最大），
索引含义见同目录 `stm32f4xx_it.c.instrumented`。

## MT6835 编码器

主机测试 `test_mt6835_crc.c` 覆盖：角度边界帧（0、1、0xfffff、0x100000、0x1ffffe、0x1fffff）、
以 9973 步长遍历 21 位原始角、独立逐位实现的 CRC（多项式 0x07、初值 0、覆盖第 2～4 字节）、
任意单比特损坏必须输出 NaN、状态位 1～7 必须输出 NaN，以及一条重构前独立记录的真实采样帧
`{0x00,0x00,0x3F,0x54,0x10,0x8E}`（原始值 518786）。角度换算为 `raw × 360 / 2097152` 度。
构建与运行命令见 [README.md](README.md) 的"可重复的主机测试"。

板上故障注入（临时固件，注入代码已移除）：

- 运行中翻转一个编码器 CRC 位：观测到故障 1（`FOC_SENSOR`）、`mt6835_errors` 加 1、六路栅极关断
  （`build/foc/sensor_crc_injected.json`）。没有实际拔掉编码器。
- SWD 阻断 SPI DMA IRQ：观测到故障 3（`FOC_TIMING`）并关断（`build/foc/watchdog_fault_confirmed_registers.json`）。
  CubeProgrammer 对该 NVIC 写操作报下载校验失败，因此只把关断状态作为观察结果，不宣称精确故障注入延迟测量。

**本台角度二次谐波补偿**：断功率滑行数据按机械角域回归得到正/反向二次余弦系数 0.52145° / 0.51646°
（二次正弦项仅 0.0230° / 0.0060°），最终采用 `mechanical_deg += 0.52*cos(2*angle)`，复用原有 sin/cos 查表，
不引入新的持久状态。相同转速区间内 Id 标准差由 0.7917 A 降至 0.3694 A（−53.3%），等效相电流 RMS 由
0.6378 A 降至 0.4010 A（−37.1%）；机械二次分量由 0.7449 A 降至 0.0373 A，电气六次分量基本保留
（0.4160 → 0.4039 A，成因未分离）。滑行拟合不是独立高精度角度计的标定；该系数属于本台编码器与磁铁安装，
更换编码器或磁铁位置后必须重新测量（证据：`build/bench_debug/20260921_1431_noise/REPORT.md`）。
编码器内部测量延迟未标定，不能把机械角与 ADC 当成绝对同时测量。

## 未验证与边界

- 未用外部仪器测 VDDA 绝对精度、母线分压或用已知电流核验相电流增益/极性；"安培"仍为标称换算。
- 未用示波器测 PA7/PB0/PB1/PC6/PC7/PC8 栅极波形、MOS 开关下的模拟建立时间或低侧采样窗口；
  500 ns 死区与 3 µs 建立时间是设计预算，不是实测值。
- 未做带载、全量程、长时热平衡与温度相关验证；1 kHz/2 kHz 遥测不能还原 20 kHz 开关纹波。
- 文中引用的证据文件在各记录目录内；`build/` 不入版本库，只在本机保留。
