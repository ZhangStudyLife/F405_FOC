# F405 电机台架

从仓库根目录运行 `download\bench.cmd`（无参数或 `run` 打开中文菜单）。菜单先选力矩、速度、位置或全量；“综合预设”使用全部档位、24 V、每工况一次。自定义固定、阶跃、斜坡、正弦、方波、三次曲线也提供幅值和时长默认值；设备、报告也可在菜单中选择。只有显式选择“全量”或使用 `run --all` 才运行全量。

```powershell
download\bench.cmd run --all --dry-run
download\bench.cmd run --mode speed --case speed_cross_zero --buses 24
download\bench.cmd run --all --dry-run
download\bench.cmd report E:\405_FOC\data\<会话时间>
```

`run --mode torque|speed|position` 跑该模式预设；`--case` 只选一个工况。电机工况必须保持 CH340 监测。默认限值是 5 A、7000 rpm、21600°，可用 `--iq-limit`、`--rpm-limit`、`--pos-limit` 缩小。全量仍要求 CH340 在线监测；学生电源在线时自动识别 DPS-150，多个有效设备需 `--psu` 指定。多母线全量要求学生电源，按 24→18→12 V 运行，每档设置并读回 5 A 母线限流。电机仍是空载台架；带 3D 打印负载可用 `--load-name`、`--load-mass-g`、`--load-stl`、`--load-axis` 记元数据。

## 工况

- **力矩**：正负静止起动阈值；先以速度模式达到 ±250/1000 rpm 后切换不同正负 Iq，记录加减速与滑行；±250/1000/4000 rpm 断电滑行；0.2/0.5/1 Hz 正弦和方波。未进入旋转态的段不用于拟合运行摩擦、惯量。
- **速度**：`0→1000→−2000→0`、1/5/25 rpm 整圈、斜坡、正弦、方波、三次曲线。
- **位置**：`position_profile_1` 往返轨迹覆盖 ±30/90/180/360/720/1800/3600°，速度/加速度/跃度为 500/5000/50000。

每个工况只采集一次完整 USB 组 0。脚本先 `stop` 等待静止，位置段再 `zero`；带初速的力矩段先达到并保持目标速度 0.2 秒。跟踪误差超标时标记后继续；保护或丢帧保存残段，断电恢复最多重试一次。实时 CH340 超过 8000 rpm 会停机；固件在 8600 rpm 保护。固件 `Iq` 参考按 10 A/s 变化。

## 文件与同步

全部文件写在 `E:\405_FOC\data\<会话时间>\`，不使用 C 盘临时目录。每个“工况阶段 × 电压 × 重复 × 尝试”生成独立 `.7z`，采用 LZMA2 高压缩级别。包含 `frames.f32`、`meta.json`、`uart.jsonl`，学生电源在线时另含 `power.jsonl`。先关闭原始文件并校验 7z，再删除未压缩暂存；失败保留暂存供排查。`session.json` 随测试增量更新。`report` 兼容 ZIP 与 7z。

`frames.f32` 每帧 15 个小端 float32 + `00 00 80 7F` 帧尾，共 **64 字节 × 2 kHz = 128,000 B/s**。0 号 float 的位表示低 24 位微秒时间戳、高 8 位状态/故障/功率；1 号 float 为低 24 位 20 kHz 采样序号，高 8 位固定为 0；相邻帧序号差 10、时间戳差 500 µs。2..14 依次为 `Id/Iq/Iq_ref/Ud/Uq/Vbus`、机械/电角、实测/目标转速、实际/目标位置和模式。`meta.json` 保存字段表、命令时间线、版本、限制、母线与连续性。电源约 2 Hz，只能反映低频母线趋势，不能作相电流或高频纹波测量。

字段名与固件写入顺序见 `benchlib.CHANNEL_NAMES`。电流、母线和编码器值来自同一控制记录；相电压仍须由母线和 PWM 模型推算，受死区、开关及采样误差影响。相电流绝对增益尚未对标准仪器校准；本轮不宣称已可靠辨识 Rs/Ld/Lq。

## 固件命令与自检

`Iq <A>` 力矩、`rpm <值>` 速度（±8600 rpm）、`pos <绝对多圈角度>` 位置；`motion <最高rpm> <加速度rpm/s> <跃度rpm/s²>` 设置后续位置轨迹。`zero` 仅静止待机可用；`stop` 关功率；`clear` 不自动重新运行。速度与位置保持上次目标直到新命令或 `stop`。

```powershell
python tools\bench\selftest.py
```

这会验证 64 字节、2 kHz 帧解析、丢帧识别、FOC3 采集解析、7z 与 ZIP 往返和限值检查。实机验收结果另存到数据目录，不以旧 USB 记录代替。

## 故障恢复与记录（2026-09-25）

预转速期间持续读取 USB；电源读回和等待期间关闭高速发送会话，避免主机自己积压数据。
异常立即记录 `failure.json`（关电源前的 MCU 状态和电源状态），先停机断电再压缩。
`session.json` 的 `power_commands` 记录脚本每次开关电源的单调时钟时间，区分主动关断与意外掉电。
电源检查要求最近 2 秒内完整状态反馈、无保护且输出开启；不能仅凭任意串口字节判定健康。

恢复先关闭并重新打开串口，恢复母线后尝试一次 clear 并检查静止待机。
无遥测、clear 后故障仍锁存或待机检查超时，均在再次关闭电源并读回确认后，识别目标并 ST-Link 完整复位一次，再重复状态检查。
复位会重新初始化 MCU 外设和控制状态；只切学生电源不能替代它，因为 MCU 仍可由 USB 供电。
恢复母线后才尝试一次 `clear`，随后验证无故障、静止待机和 CH340 健康，重跑当前段。
电源串口失联时重连一次并重新核实关闭；保护未消失、复位失败或当前段再次失败则保存现场并停止。
交互入口回到菜单，常见串口/外部程序错误不再显示 Python traceback。
持续吞吐不足不能靠反复复位修复，不把有缺口的残段标为通过。

回归测试：`python tools/bench/test_recovery.py`、`python tools/bench/selftest.py`。
